# 휴가·휴직 관리 (오프라인 · 폴더 저장형)

보안망 PC에서 인터넷 없이 동작하는 HTML 단일 파일 프로그램. **육아휴직** 대장과 **육아휴직 外** 대장(가족돌봄·공상·난임·명령·무급·의병휴직) 포함(테스트 단계).

## 사용법
1. `dist/육아휴직관리.html` 을 PC에 저장 후 **Edge 또는 Chrome**으로 열기
2. 첫 화면에서 **데이터 폴더 선택** → 예) `D:\인사\휴가관리`
   - 폴더 안에 `hr-data.json`(원본), `backup\`(일별 백업 30개), `export\`(엑셀 내보내기 결과)가 생김
   - 다음 실행부터는 "지난 폴더 다시 연결" 클릭 1회로 진입 (브라우저 보안정책)
3. **엑셀 업로드**로 기존 대장 불러오기 → 시트 선택 → 컬럼 매핑 확인 → 미리보기 → 가져오기
4. 이후 등록·수정은 화면에서 직접, 저장은 자동

## 구조
| 경로 | 내용 |
|---|---|
| `src/app.html` | 앱 소스 (UI + 로직) |
| `vendor/xlsx.full.min.js` | 엑셀 읽기/쓰기 라이브러리 (SheetJS 0.18.5, Apache-2.0) |
| `build.py` | `src` + `vendor` → `dist/육아휴직관리.html` 단일 파일 생성 |
| `dist/육아휴직관리.html` | 배포용 파일 (이것만 복사하면 됨) |
| `design/` | 디자인 시안 |

빌드: `python3 build.py`

## 육아휴직 계산 규칙 (설정에서 변경 가능)
개월 수는 **엑셀 DATEDIF 방식**: 종료일+1 기준 달력 개월수 + (나머지 일수 ÷ 종료일이 속한 달의 일수), 소수 3자리 버림.

- 한도 = 기본 12개월. 배우자가 같은 자녀로 3개월 이상 육아휴직 사용(6+6) 시 **+6개월 → 18개월**. 같은 자녀의 어느 차수에든 "+6" 표시하면 그 자녀 전체에 적용
- 예정기간 = calcMD(시작일, 종료일) → "N개월 M일" + 개월 소수
- 복직(퇴직)예정일 = 종료일 + 1일 (요일·공휴일 무관, 휴직은 달력 기준 연속 상태)
- 사용기간 = calcMD(시작일, min(기준일, 종료일))
- 과거 사용기간합 = 같은 사번 + 같은 자녀명의 이전 차수 개월 합
- 잔여기간 = 한도 − 과거합 − 이번 예정기간 (개월). 음수면 빨간 표시(한도 초과)
- 잔여 이어 쓸 때 종료일 = calcEndDate(복직예정일 또는 오늘 중 늦은 날, 잔여개월): 정수 개월은 달력 이동, 소수부는 도착한 달의 일수로 환산, −1일
- 분할차수 = 같은 자녀의 시작일 순서로 자동 부여
- 비고 = `1차 2025.09.01~2025.11.30(3개월), …` 자동 생성 + 수기 메모
- 복직완료(빨간 글씨) = 실제 복직일 입력됨 또는 기준일 ≥ 복직예정일

산식 원본: `docs/육아휴직_산식.md` (참고용 로직, 고용24 판정과 차이 가능)

## 육아휴직 外 규칙
- 인적사항 7개(소속·사번·성명·직급·직위·직무·직군)는 두 대장이 직원 마스터를 공유
- 발령구분: 가족돌봄휴직 · 공상휴직 · 난임휴직 · 명령휴직 · 무급휴직 · 의병휴직
- 기본값: 공상휴직 = 유급·근속 산입, 의병휴직 = 80%·미산입, 나머지 무급·미산입 (수정 가능)
- 사용차수: 담당자 입력 (자동 계산 없음)
- 과거사용기간: 등록/수정 화면에서 같은 사번의 과거 건을 체크해 연결한 일수 합
- 한도(설정에서 변경): 가족돌봄휴직 90일(연단위, 가족돌봄휴가 사용일 수기 차감) · 난임휴직 180일 · 의병휴직 180일 · 나머지 한도 없음(잔여 빈칸)
- 기간은 전부 일수. 복직(예정)일 = 종료일 + 1
