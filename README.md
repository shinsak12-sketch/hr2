# 휴가·휴직 관리 (오프라인 · 폴더 저장형)

보안망 PC에서 인터넷 없이 동작하는 HTML 단일 파일 프로그램. 현재 **육아휴직** 모듈만 포함(테스트 단계).

## 사용법
1. `dist/육아휴직관리.html` 을 PC에 저장 후 **Edge 또는 Chrome**으로 열기
2. 첫 화면에서 **데이터 폴더 선택** → 예) `D:\인사\휴가관리`
   - 폴더 안에 `hr-data.json`(원본), `backup\`(일별 백업 30개), `export\`(엑셀 내보내기 결과)가 생김
   - 다음 실행부터는 "지난 폴더 다시 연결" 클릭 1회로 진입 (브라우저 보안정책)
3. **엑셀 업로드**로 기존 대장 불러오기 → 시트 선택 → 컬럼 매핑 확인 → 미리보기 → 가져오기
4. 이후 등록·수정은 화면에서 직접, 저장은 자동

## 구조
| 경로 | 내용 |
|---|---|
| `src/app.html` | 앱 소스 (UI + 로직) |
| `vendor/xlsx.full.min.js` | 엑셀 읽기/쓰기 라이브러리 (SheetJS 0.18.5, Apache-2.0) |
| `build.py` | `src` + `vendor` → `dist/육아휴직관리.html` 단일 파일 생성 |
| `dist/육아휴직관리.html` | 배포용 파일 (이것만 복사하면 됨) |
| `design/` | 디자인 시안 |

빌드: `python3 build.py`

## 육아휴직 계산 규칙 (설정에서 변경 가능)
- 예정기간 = 종료일 − 시작일 + 1
- 복직(퇴직)예정일 = 종료일 + 1 (주말·공휴일이면 다음 영업일, 설정으로 끌 수 있음)
- 사용기간 = 기준일 기준 경과일 (종료 후엔 예정기간)
- 과거 사용기간합 = 같은 사번 + 같은 자녀명의 이전 차수 합
- 잔여기간 = 한도(기본 365일) − 과거합 − 이번 예정기간
- 분할차수 = 같은 자녀의 시작일 순서로 자동 부여
- 비고 = `1차 2025.09.01~2025.11.30(91일), …` 자동 생성 + 수기 메모
- 복직완료(빨간 글씨) = 실제 복직일 입력됨 또는 기준일 ≥ 복직예정일
